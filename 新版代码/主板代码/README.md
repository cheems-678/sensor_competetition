## 下载方式

1. ST-Link V2 通过 SWD 接口下载(SWDIO + SWCLK + GND + 3V3)
2. USB-CDC 串口通过 STM32 Flasher 下载(需BOOT0=1)
3. USB-CDC 供电 + 串口调试(@115200bps)

## 软件工程结构

```
code/
├── Core/
│   ├── Inc/
│   └── Src/
│       └── main.cpp          主程序(三模式切换+按键+显示调度)
└── Hardware/
    ├── Inc/
│   │   ├── config.h          全局配置(引脚+参数+数据结构)
│   │   ├── tomography.h      层析重建算法接口
│   │   ├── sensor.h           传感器驱动接口
│   │   └── display.h         TFT显示接口
    └── Src/
        ├── tomography.cpp     ART重建+射线追踪+异常分类
        ├── sensor.cpp         DAC发射+ADC采样+换能器切换
        └── display.cpp        ILI9341显示+热力图+波形
```

需要在Keil MDK中新建工程, 添加以上源文件, 选择STM32F103C8芯片, 包含HAL库。
