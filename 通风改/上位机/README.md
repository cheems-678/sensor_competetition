# 上位机

当前可用的智能通风系统上位机统一放在此目录。

当前版本使用 LoRa 应用协议 v4：固定单组、18 字节单遥测帧、两路风机占空比控制。传感器未接入阶段，无效占位值统一显示为 `--`，数据写入新表 `telemetry_v4`，不会改动旧表。

## 主从双 BME280 联调约定

- 主机 BME PB10/PB11 软件 I²C 保持不变；从机 BME PB6=SCL、PB7=SDA，I2C1 硬件 100 kHz。BH1750 删除、DHT11 停用，灯带仍独立闪烁，风机仍 PB1/PB8。
- 18 字节数据区：flags bit0=首组为主机 BME、bit1=双 BME 布局、bit2=本轮从机通信在线。flags=3 或 7；偏移 1–8 为主机温度 int16×10、湿度 uint16×10、绝对气压 uint32 Pa，9–16 为从机同三项，17=0xFF。多字节小端，无效值 0x8000/0xFFFF/0xFFFFFFFF。在线不等于 BME 正常，传感器故障仍可收到从机占位应答。
- 界面显示主从各三项和从机链路状态，无效值为 `--`，保留两路风机。31 字节整帧、v4 和 CRC 不变。flags=0 保持旧布局，flags=1 保持单主机 BME 解释；未知布局不冒认来源。
- 串口连接后每秒请求缓存，已有遥测请求或风机 ACK 待确认时暂停自动轮询；遥测等待最长 5 秒。断开连接停止请求并清除当前显示，重连不自动启动风机。“读取单帧”请求一次新测量。
- 数据库结构和历史记录不改。原 `slave_temperature_c/slave_humidity_pct/slave_pressure_pa` 列继续存储偏移 1–8，结合 flags 判断来源（0=旧从机，1/3/7=主机）；双 BME 布局的旧声学/雨滴/DHT 列存 NULL，从机三项完整保留在 raw_frame 中，回读须按 flags 解码。不是数据库迁移。
- 主机固件与上位机须配套更新；控制室保持透传及关闭自身自动轮询，不需重新烧录。硬件验证须在用户烧入最新 HEX 后完成。
- 本轮只验证从机 BME 上传；声学与雨滴待验证成功后另行扩展，不提前实现。

## 目录约定

- `main.py`：唯一的上位机源码入口。
- `智能通风系统.exe`：由 `main.py` 打包生成的可执行文件。
- `tests/`：只存放上位机 Python 测试，不放 STM32 固件测试。

## 风扇控制约定

- 滑块显示整数百分比，松开鼠标或释放调节按键后发送；数字框可输入 0–100，再点“发送”。不在拖动过程中连续发送，避免占用 LoRa 链路。
- 每路显示待发送、等待确认、已确认或超时；仅收到匹配流水号的成功 ACK 才视为主机已执行。ACK 不代表风扇实际转速测量。
- 输入为空、非数字、非有限值或超出 0–100 时拒绝发送；未连接时不保存待发送指令，重连不会自动启动风扇。
- 风扇编号和 GPIO 标签必须与主机 `fan_pwm.c` 一致；本次硬件驱动接法确认前不远程启动风扇。
- 仅保留风机1/PB1、风机2/PB8，通道号仍为1和2；风机3/PA1、风机4/PB9暂时停用，移除滑块并拒绝发送通道3/4指令。外接 MOS 管，占空比是 PWM 高电平比例，不是实测 RPM。主机启动默认 0%。
- 须配套更新主机固件并重启此上位机；协议版本与帧格式仍为 v4。早期四路版本的 GPIO 顺序与本版本不同，不使用旧界面混测。

## 运行与验证

```powershell
python .\main.py
python -m unittest discover -s .\tests
```

打包时从本目录执行：

```powershell
python -m PyInstaller --noconfirm --onefile --windowed --name 智能通风系统 --distpath . --workpath .\build --specpath .\build main.py
```
