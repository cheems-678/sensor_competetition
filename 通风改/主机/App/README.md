# 主机 v4 架构

主机使用裸机主循环处理 LoRa 遥测、PB10/PB11 BME280、两路 PWM 风机和 PB13 常亮灯带。

## 主机 BME280 联调约定

- BME280 驱动放在现有 `Core/Inc/BME280.h`、`Core/Src/BME280.c`；业务采样与缓存放在 `App/master_bme280.*`，不引入 RTOS。
- PB10=SCL、PB11=SDA，开漏软件 I²C，DWT 提供微秒时序；需要模块上拉至 3.3 V。BH1750 驱动及其运行逻辑删除，不再配置 I2C2。PA5 DHT11 源码保留但不参与编译。
- 每秒强制模式采样一次，温湿压均 ×1 过采样、关闭滤波；转换等待采用主循环状态机，不调用阻塞式 ReadAll。失败立即使缓存无效、1 秒后重试，超过 2 秒的数据无效。
- RAM 的 `MasterBme280Diag` 记录地址、芯片 ID、校准有效状态、采样计数、错误及更新时间，不通过 LoRa 发送调试文本。
- 遥测走控制室→主机→从机→主机→控制室；参数 0 读取缓存，参数 1 等待主从各一次新测量。主机按角色、组号、独立递增的从机流水号匹配回复，等待初值 500 ms（从实际 UART 发出计时）。从机失联仍上传主机数据和从机无效值，不再只回复 ERROR=2。风扇设置立即执行，ACK 在当前从机接收窗口结束后发送，避免半双工冲突。
- 帧仍为 v4，数据区 18 字节、整帧 31 字节。偏移 0：bit0=主机 BME 位于首组字段，bit1=双 BME 布局，bit2=本轮匹配到从机应答；本轮 flags=0x03（从机离线）或 0x07（通信在线，传感器是否有效另看占位值）。1–2/3–4/5–8 为主机温度 int16×10、湿度 uint16×10、绝对气压 uint32 Pa；9–10/11–12/13–16 为从机同三项；17=0xFF 预留，均小端。无效值为 0x8000、0xFFFF、0xFFFFFFFF。
- 0x00 旧布局和 0x01 单主机 BME 帧保留上位机兼容解释。声学/雨滴本轮不接入；双 BME 验证后再扩展数据区到 22 字节，不能将本轮 9–16 按旧声学/雨滴/DHT11 字段解析。
- 控制室保持自动轮询关闭、原样透传，本轮不需重烧。更新后的上位机每秒轮询，风扇指令优先。主机、从机 HEX 和上位机配套更新，由用户烧录，不自动开风扇。
- TIM1 专供 WS2812，发送完成后停止并将 PB13 拉低，不再恢复 DHT11 计时；TIM3/4 风扇配置保持不变。
- 验证先做 Keil 构建和上位机单测，再由用户烧写主机；硬件验收包含地址/ID/校准/采样、传感器断开与恢复、至少 5 分钟连续遥测及风扇/灯带回归。
- 主机 `tests/` 用于电脑侧 C 状态机与遥测回归测试，不加入 Keil 固件；目录结构和运行方式见该目录 README。

```text
USART2 ISR -> 环形缓冲 -> LoraP2PRX -> 事件队列 -> MasterRuntime
                                                        |          |
                                                   q_lora_tx    FanPwm
                                                        |          |
                                                     LoraP2PTX   PB1/PB8
```

- 固定组号：`1`。
- 主循环依次执行 `LoraP2PRX`、`MasterRuntime_ProcessOne`、`LoraP2PTX`，无 RTOS。
- USART2 中断收字节，主循环负责流式拆帧和完整帧发送。
- `FanPwm`：两路独立高有效 PWM，25 kHz，0–100%。
- 保留已验证的风机1/通道1=PB1（TIM3 CH4）、风机2/通道2=PB8（TIM4 CH3），两路均配置为复用推挽输出，启动默认 0%，不自动起转。定时器使用 72 MHz / 2880 的 PWM 周期。
- 风机3/PA1、风机4/PB9 暂时停用：两引脚配置为输入下拉，避免栅极悬空；不启动 TIM2 PWM，TIM4 CH4 禁止输出。通道3/4指令返回失败 ACK（`10 01`），不会影响风机1/2。
- 主机与上位机须配套更新，核对上述编号与 GPIO 标签；控制室仅转发指令，不需重新烧录，协议版本和帧格式仍为 v4。通道1/2的含义保持一致；早期四路版本的编号与本版本不同，不用旧界面混测。
- ACK 仅表示指令已执行，不是转速反馈；停用功能不能修复 MOS 或接线故障。
- DGUS、USART1 屏幕、USART3 Modbus、TD710 自动控制已移除；BME 以裸机状态机运行。
- 18 字节遥测区按上述 BME 来源标志解释，DHT11 字段保持无效占位。

## 灯带联调约定

- WS2812 固定常亮；BH1750 已删除，PB10/PB11 专供 BME280。
- WS2812 固定 30 颗，PB13 连接 DIN；上电后以 RGB 白色、每通道 51/255（20%）点亮一次并保持该状态。
- 灯带状态不进入 LoRa 遥测数据区，不再实现光照自动控制。
- 灯带 5 V 来自板载 12 V 降压电源并与 MCU 共地。PB13 为 3.3 V 直连 DIN；若现场出现首灯不响应、闪烁或误码，应增加 3.3 V→5 V 电平转换。

## 历史主从通信联调记录（不适用于当前主机 BME 模式）

- 当前先做控制室→主机的风扇联调，从机不供电。控制室 `Bsp/gateway_runtime.h` 的 `GATEWAY_AUTO_POLL_ENABLED=0` 关闭自动遥测轮询；需恢复传感器联调时再置为 1。
- 滑块发送 `0x10`（风扇编号、占空比），主机直接设置 PWM 并返回同流水号 `0x20`（`10 00` 表示执行成功，`10 01` 表示设置失败），不转发从机，不等待从机应答。控制室核对 ACK 中的命令类型后转发上位机。
- 本次不改变射频参数或协议版本。当前回滚基准 `cb7ddf1` 的源码是 v4；板载旧 v3 固件不能与当前上位机、主机源码混用，烧录前核对两个工程生成的 HEX。仅手动点击“读取单帧”仍走下述从机遥测流程，风扇联调时不点击该按钮。
- 正常模式关闭 `MASTER_DIRECT_DHT11_TELEMETRY`：控制室请求先转发从机，收到相同流水号的从机遥测后再回复控制室。
- 本轮先定位链路故障，不改变 18 字节数据区、从机占位值、3 秒应答超时或射频参数。
- `MasterRuntimeDiag` 在 RAM 中记录转发次数、匹配/不匹配的从机应答、最后流水号和应答耗时；耗时从请求入发送队列开始，包含发送等待，不等于纯空口耗时。
- 主机入队/串口发送成功不能单独证明无线成功，必须结合从机收包及主机匹配应答计数验证。
- 未获取从机运行状态之前，不将 UART 错误恢复缺失或射频配置失败直接认定为现场根因。

- 用户逐个接入并确认：主机 ST-Link `37FF71064E57343684051343`，从机 ST-Link `37FF71064E57343641061343`。此对应关系仅适用于当前探针与板子的接线，后续换线必须重新确认。
- 调试工具配置检查通过，检测到两个探针。使用 ST-LINK CLI 按完整序列号 HOTPLUG 只读采样，不在实时收发途中停核，避免调试暂停制造串口溢出和超时。
- 从机 Flash 与本地从机 HEX 比较无差异；本轮未修改或烧写从机。
- 主机关闭 DHT11 单机旁路后烧写、校验通过，恢复控制室→主机→从机→主机→控制室的遥测路径；DHT11 驱动、从机占位数据与射频参数保持不变。
- 本轮烧写前的 Flash 备份命令缺少 `0x` 前缀，工具按十进制误解析地址而失败，未取得有效的本轮烧写前备份。后续地址和长度必须显式带 `0x`，并检查备份结果成功后才能继续烧写。
- 最终采样：125 次控制室请求、125 次主机转发、125 次匹配从机应答、125 次主机遥测回复；主机串口累计收发各 250 帧。超时、流水号不匹配、CRC 拒收及 UART 发送错误均为 0，最大队列到应答耗时 221 ms；同一阶段 DHT11 51 次采集全部成功。从机 CRC 错误、接收溢出和发送失败均为 0。该结果证明当前链路可用，不足以断言历史超时的唯一根因。

## 历史 DHT11 实现约定（驱动已停用）

- SysTick：HAL 毫秒时基；启动时显式将 VTOR 设为 Flash 向量表。
- TIM1：常态为 DHT11 的 1 MHz 自由运行计数器；灯带每秒切换状态时，短暂切换为 800 kHz WS2812 PWM，通过 DMA1 Channel 2 发送后立即恢复。DHT11 读取与灯带发送都在主循环中串行执行，不得并发访问 TIM1。
- TIM3/4：风扇 PWM 占用，不得借用为 HAL 时基或修改周期；TIM2 不再用于风扇 PWM。
- DHT11 使用 PA5，开漏拉低启动、输入上拉释放总线；按 TIM1 实测高电平脉宽解码 40 位并验证校验和。
- 上电等待至少 2 秒，每次实际读取间隔至少 2 秒；读取时保持 USART2 中断可用，所有边沿等待必须有超时。
- `MasterDht11Diag` 仅保存在 RAM，记录最后错误、响应脉宽、原始五字节和每位脉宽，不通过 LoRa 插入调试文本。
- 后续换引脚仅修改驱动 GPIO 宏并核对板级复用关系，未经确认不变更实际接线。
