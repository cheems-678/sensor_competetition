# 热点网页同步上位机交付说明（2026-10-07）

## 本次功能

网页仍为ESP8266本地热点的 http://192.168.4.1 ，共十页：粮仓总览、环境监测、粮面测距、雨滴、烟雾、声学、智能预警、四路风机、四路窗口和操作记录。

- 主从机气压显示kPa，传输仍为Pa；环境曲线保留本次浏览最近10分钟、最多1200点，缺失留断点，CSV导出包含真实采样与单位。
- 五路MAX4466对应主机PA0/PA4/PA6/PB0/PA5；透明仓体模型五点同高、间隔72°，可旋转/缩放/复位。0是有效幅度；阈值0..4095整数，留空禁用，统一应用，超限提示。切页保留，网页刷新清空。
- 主机只广播采集年龄小于300ms的声音窗口。网页显示“最近上传窗口”及累计源年龄，累计达到2000ms后未知，防止每秒广播与短采集窗口导致频繁空白；不表示持续监听、声音识别或声源定位。
- 风机高100/中90/低80/关闭0；动画由确认的PWM设置驱动，不代表实测转速。受理和等待不当作成功；成功确认不被同一份旧广播覆盖，超时/失败显示未知，等新的有效设备状态。隐藏、离屏和减少动态效果停止动画。
- 窗口继续使用连续旋转舵机的定时动作和原主机→从机→ACK链路；确认仅表示PWM设置成功，实际开度未知。
- 测距新增仓体剖面与距离图示，实际有效范围5–50cm，不换算真实粮高或储量。
- 雨滴1提示降雨，烟雾相对指数>10提示超限；距离<10cm提示过近，>=11cm连续有效3秒恢复，失效中断恢复。原始数据无效/过期时为未知，防闪动保留的数值不参与判定。烟雾指数未标定，不是ppm或消防报警判据。
- 环境趋势120秒，温度默认0.4℃/min、湿度1百分点/min，阈值可修改；自动默认关闭，满窗口后超限30秒确认、低于阈值80%60秒恢复，超过10秒无新有效采样重新积累。手动检查满窗口即提示超限，报告冻结到点击时刻，可导出JSON。事件最多200条，只在本次浏览器内存保留；不自动控制设备。真实AI分析仍需独立联网服务，本版本为本地规则检查。

原监测防闪动、请求串行、超时取消/不重发、控制室46字节遥测和上位机接口保持。03状态新增42字节layout2，兼容旧26字节layout1；网页兼容旧主机，缺少声音时显示未知。
